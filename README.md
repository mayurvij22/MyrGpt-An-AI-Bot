## ✨ Features

- Chat-style interface with separate **user** and **AI** message bubbles
- Responses generated by the **Google Gemini API**
- A **loading animation** while the reply is being generated
- Plain HTML, CSS and JavaScript with no frameworks or build step

## 🛠️ Tech stack

| Layer | Technology |
|---|---|
| UI | HTML5, CSS3 |
| Logic | Vanilla JavaScript, Fetch API |
| AI | Google Gemini (Generative Language API) |
| Hosting | Vercel |

## 🚀 Run locally

```bash
git clone https://github.com/mayurvij22/MyrGpt-An-AI-Bot.git
cd MyrGpt-An-AI-Bot
```

1. Get a free API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Put the key into the API URL in `index.js`.
3. Open `index.html` in your browser.

> [!WARNING]
> In a frontend-only app the API key is visible to anyone who opens the page. For public deployments,
> move the Gemini call behind a small backend (for example a Vercel serverless function) and keep the key in an
> environment variable.

## 📁 Project structure

```text
├── index.html   # Chat layout (header, chat container, prompt box)
├── style.css    # Styling for messages and the loader
└── index.js     # Sends the prompt to Gemini and renders the reply
```
